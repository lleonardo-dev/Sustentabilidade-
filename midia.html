Recursos multimídia

Vídeo, áudio e conteúdo institucional reunidos para complementar o aprendizado sobre o tema.

Vídeo: respiração guiada

Uma animação simples, produzida para este projeto, que ilustra um exercício básico de respiração — uma técnica frequentemente citada como recurso de autocuidado para momentos de tensão.

Vídeo original produzido para este projeto acadêmico. Não substitui orientação profissional.

Áudio: pausa de atenção plena

Uma faixa sonora curta e calma, pensada para acompanhar um momento breve de pausa e respiração consciente.

Faixa sonora original, gerada para este projeto acadêmico.

Mente Viva
