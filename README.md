# Mente Viva

Projeto acadêmico de **Front-End para Web** sobre **Saúde Mental, Qualidade de Vida, Prevenção e Promoção**.

## 👥 Integrantes

* Kayke Queriquieri
* Jonathan Nery
* Ruan Sousa
* Vinicius de Oliveira

## 🎯 Objetivo

Criar um protótipo de site informativo sobre saúde mental, qualidade de vida, prevenção, bem-estar, acessibilidade e impacto social.

## 🌐 Páginas

O projeto possui 10 páginas interligadas:

* Início
* Sobre
* Prevenção
* Impacto Social
* Acessibilidade
* Galeria
* Mídia
* Notícias
* Contato
* Orçamento

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* SVG
* Áudio
* Vídeo

## ♿ Acessibilidade

O protótipo conta com recursos como:

* Navegação por teclado
* Texto alternativo nas imagens
* Contraste adequado
* Controle de fonte
* Alto contraste
* Estrutura semântica
* Layout responsivo

## 📱 Responsividade

O site foi desenvolvido para diferentes dispositivos:

* Desktop
* Notebook
* Tablet
* Celular

## 🌱 Impacto Social

O projeto aborda saúde mental relacionando o tema a:

* Inclusão
* Acessibilidade
* Prevenção
* Bem-estar
* Qualidade de vida
* Acesso à informação

## 🖥️ Protótipo

Esta é a primeira versão do projeto, desenvolvida para demonstrar sua estrutura, navegação e proposta visual.
